# Задание 1. Реализация кватернионов на Python
Выполнил: Миронов Василий 

Этот проект содержит реализацию кватернионов на Python, предоставляющую методы для выполнения арифметических операций, нормализации, нахождения сопряжения, инверсии и преобразования в матрицы вращения. Также поддерживается создание кватернионов из оси вращения и угла.

## Описание класса

Класс `Quaternion` представляет кватернион следующего вида:

\[ q = a + bi + cj + dk \]

Где:
- `a` — скалярная часть.
- `b`, `c`, `d` — векторные части, соответствующие `i`, `j` и `k`.

### Основные возможности:
- **Арифметические операции**:
  - Сложение: `q1 + q2`
  - Вычитание: `q1 - q2`
  - Умножение: `q1 * q2`
- **Свойства**:
  - Норма: `q.norm()`
  - Сопряжение: `q.conjugate()`
  - Инверсия: `q.inverse()`
- **Преобразования**:
  - Преобразование в матрицу вращения 3x3: `q.to_rotation_matrix()`
  - Создание из оси и угла: `Quaternion.from_axis_angle(axis, angle)`

## Примеры использования

### 1. Создание кватернионов
```python
q1 = Quaternion(1, 2, 3, 4)
q2 = Quaternion(2, 4, 6, 8)
```

### 2. Арифметические операции
#### Сложение:
```python
q_sum = q1 + q2
print("Сумма:", q_sum)
```
_Вывод:_
```
Сумма: Quaternion(3, 6, 9, 12)
```

#### Умножение:
```python
q_product = q1 * q2
print("Произведение:", q_product)
```
_Вывод:_
```
Произведение: Quaternion(-56, 8, 12, 16)
```

### 3. Норма кватерниона
```python
print("Норма q1:", q1.norm())
```
_Вывод:_
```
Норма q1: 5.477225575051661
```

### 4. Обратный кватернион
```python
q_inverse = q1.inverse()
print("Обратный q1:", q_inverse)
```
_Вывод:_
```
Обратный q1: Quaternion(0.03333333333333333, -0.06666666666666667, -0.1, -0.13333333333333333)
```

### 5. Кватернион из оси и угла
Создание кватерниона, представляющего вращение на 45 градусов вокруг оси Z:
```python
axis = [0, 0, 1]  # Ось Z
angle = math.pi / 4  # 45 градусов
q_rotation = Quaternion.from_axis_angle(axis, angle)
print("Кватернион вращения:", q_rotation)
```
_Вывод:_
```
Кватернион вращения: Quaternion(0.9238795325112867, 0.0, 0.0, 0.3826834323650898)
```

### 6. Матрица вращения из кватерниона
Преобразование кватерниона в матрицу вращения 3x3:
```python
rotation_matrix = q_rotation.to_rotation_matrix()
print("Матрица вращения:")
for row in rotation_matrix:
    print(row)
```
_Вывод:_
```
Матрица вращения:
[0.7071067811865475, -0.7071067811865476, 0.0]
[0.7071067811865476, 0.7071067811865475, 0.0]
[0.0, 0.0, 1.0]
```

# Задание 2. Декоратор кэширования в Python
Выполнил: Васильев Вадим

Этот решение демонстрирует реализацию декоратора для кэширования результатов выполнения функций с использованием стандартной библиотеки Python. 

## Описание декоратора

`caching_decorator` — это декоратор, позволяющий сохранять результаты выполнения функций в кэше для ускорения последующих вызовов с теми же аргументами. 

### Основные возможности:
- **Кэширование результатов**: при повторном вызове функции с одинаковыми аргументами результат берется из кэша, без выполнения вычислений.
- **Ограничение размера кэша**: при достижении заданного размера кэша самые старые записи удаляются.
- **Поддержка нескольких функций**: каждая декорированная функция имеет свой собственный кэш.

## Примеры использования

### Примеры функций с кэшированием

#### Функция для вычисления квадрата числа:
```python
@caching_decorator(cache_size=2)
def func1(a):
    print("Выполняется функция func1")
    return f"{a}^2 = {a*a}\n"
```

#### Функция для умножения двух чисел:
```python
@caching_decorator(cache_size=2)
def func2(a, b):
    print("Выполняется функция func2")
    return f"{a} * {b} = {a*b}\n"
```

### Тестирование
```python
def testing():
    print(func1(4))  # Выполняется, так как кэш еще пуст
    print(func1(5))  # Выполняется, результат не в кэше
    print(func1(4))  # Извлечение из кэша
    print(func1(6))  # Выполняется, кэш переполняется, удаляется старое значение
    print(func1(4))  # Выполняется заново, так как результат был удален из кэша

    print(func2(2, 4))  # Выполняется, кэш пуст
    print(func2(2, 4))  # Извлечение из кэша
    print(func2(1, 4))  # Выполняется, новое значение
    print(func2(1, 6))  # Выполняется, кэш переполняется
    print(func2(2, 4))  # Выполняется заново, значение удалено из кэша

if __name__ == "__main__":
    testing()
```

### Вывод тестирования

```

Выполняется функция func1
5^2 = 25

Из кэша 16

Выполняется функция func1
6^2 = 36

Выполняется функция func1
4^2 = 16

Выполняется функция func2
2 * 4 = 8

Из кэша 8

Выполняется функция func2
1 * 4 = 4

Выполняется функция func2
1 * 6 = 6

Выполняется функция func2
2 * 4 = 8
```

# Задание 3. Фигуры на плоскости
Выполнил: Середа Даниил

Этот решение демонстрирует корректное наследование класса `Square` от класса `Rectangle`, не нарушающее принцип подстановки Барбары Лисков. Для решения этой проблемы добавлены свойства для синхронизации сторон квадрата.

## Описание классов

### Класс `Shape`
Базовый класс для геометрических фигур. Содержит атрибуты для хранения координат (`x`, `y`) и метод для текстового представления объекта.

#### Атрибуты:
- `x` — координата по оси X.
- `y` — координата по оси Y.

#### Методы:
- `__str__`: Возвращает строку с информацией о позиции фигуры.

### Класс `Rectangle`
Класс для представления прямоугольников, унаследованный от `Shape`. Добавляет атрибуты для ширины и высоты, а также метод вычисления площади.

#### Атрибуты:
- `width` — ширина прямоугольника.
- `height` — высота прямоугольника.

#### Методы:
- `area`: Вычисляет площадь прямоугольника.
- `__str__`: Возвращает строку с информацией о позиции, ширине и высоте прямоугольника.

### Класс `Square`
Класс для представления квадратов, унаследованный от `Rectangle`. Добавляет управление стороной квадрата, обеспечивая синхронизацию ширины и высоты.

#### Атрибуты:
- `side` — длина стороны квадрата. Связывает значения `width` и `height`.

#### Методы:
- Геттеры и сеттеры для `width`, `height` и `side` для корректного управления размерами квадрата.
- `__str__`: Возвращает строку с информацией о позиции и длине стороны квадрата.

## Примеры использования

### 1. Работа с прямоугольником
Создаем прямоугольник и увеличиваем его ширину в 2 раза:
```python
rect = Rectangle(2, 4)
print(rect)  # Rectangle at (0, 0), width: 2, height: 4
increase_width(rect)  # Увеличиваем ширину вдвое
print(rect)  # Rectangle at (0, 0), width: 4, height: 4
```

### 2. Работа с квадратом
Квадрат автоматически синхронизирует ширину и высоту:
```python
square = Square(2)
print(square)  # Square at (0, 0), side: 2
increase_width(square)
print(square.height, square.width)  # 4, 4

# Изменяем сторону квадрата:
square.side = 5
print(square)  # Square at (0, 0), side: 5
print(square.height, square.width)  # 5, 5

# Изменяем высоту (и ширина синхронизируется):
square.height = 3
print(square)  # Square at (0, 0), side: 3
print(square.height, square.width)  # 3, 3
```

### 3. Вычисление площади
Прямоугольники и квадраты поддерживают метод вычисления площади:
```python
rect = Rectangle(2, 4)
print(f"Rectangle area: {rect.area()}")  # 8

square = Square(2)
print(f"Square area: {square.area()}")  # 4
```
